## Методика и её границы

| Что | Как получено | Чего это не значит |
|---|---|---|
| Показы, позиции, запросы | Search Console API, окно 90 дней 2026-06-10 — 2026-09-07 (данные финализируются с лагом 2 суток) | Позиция — средневзвешенная по показам; на объёмах < 10 показов не интерпретируется |
| Сверка на свежесть | то же, окно 28 дней 2026-08-11 — 2026-09-07 | Разброс 28-дневного окна на нашем объёме ±40% неделя к неделе |
| **Дата деплоя** | история успешных запусков `deploy-frontend.yml` (GitHub Actions) + проверка предком: для каждой статьи взят первый успешный деплой, в который попал коммит её создания | Не дата коммита. Расхождение доходит до 6 дней (22.07 → 28.07) |
| Статус индексации | `indexation.py` (URL Inspection API), кэш от 2026-09-09 | «Проиндексирована» — состояние на дату проверки, не дата попадания в индекс |
| **Возраст в индексе** | оценка по первому дню с показами в GSC (окно 180 дней) | Google не отдаёт дату индексации. Для страниц без единого показа возраст в индексе установить нельзя — они помечены `—` |
| Страна спроса | GSC, срез `country × page` | Суммы по странам меньше сумм по страницам: часть данных анонимизируется. Доли — ориентир, не точные числа |

Пороги значимости — как во всём контуре: **< 10 показов за период — шум**,
**сдвиг позиции < 3 пунктов — не сигнал**, **отсутствие кликов на позиции ниже 20 ничего
не доказывает**.
