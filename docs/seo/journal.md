# Журнал SEO-решений

Заполняет скилл `seo-analyst` при каждом запуске. Нужен, чтобы через месяц
можно было ответить «помогла ли правка сниппета» и чтобы одна и та же
отвергнутая идея не всплывала каждый день.

Формат записи:

```
## YYYY-MM-DD
Показы 28д: N (дельта) · позиция X.X (дельта) · в индексе: N/M
Задачи: краткий список
Решил не делать: ...
```
